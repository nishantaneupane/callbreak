# Callbreak (web)

Play at **https://nishantaneupane.github.io/callbreak/**

The Nepali calls-and-tricks card game: four players, 13 cards each, spades are always trump. Call how many tricks
you'll take, then play 13 tricks; five rounds make a game. Practice against computer players or play online.

This repository holds only the built web version, served by GitHub Pages. It's replaced by each new web build.
